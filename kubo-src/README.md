# Кубо: Небесные острова — исходники

3D-платформер: три уровня, монеты, двойной прыжок, лифты, падающие настилы, чекпоинты.
Играть: папка [`../kubo/`](../kubo/) на GitHub Pages этого репозитория. Первая версия с мультяшной графикой сохранена в [`../kubo-classic/`](../kubo-classic/).

Уровни, физика и управление — те же, что в первой версии. Заменена графика: вся она построена кодом, без готовых наборов моделей.

## Откуда графика

| Что | Как сделано |
|---|---|
| Герой (робот-куб), монета, блоки, платформы, лифты, постаменты | геометрия по размерам в `blender/kit.py`, материалы и запекание в `blender/kitbake.py` → один атлас 2048 px (цвет, нормали, шероховатость/металл/затенение) |
| Фонарь «летучая мышь» (чекпоинты и финиш) | `blender/lamp_parts.py` + `blender/lamplow.py` |
| Бесшовные текстуры камня, скалы и травы | `blender/cells.py` (периодическая карта ячеек Вороного) + `blender/tiles.py` (шум на 4D-торе — стык плитки точный) |
| Острова | строятся при загрузке уровня в `src/gfx.js` (`makeIsland`): каменный бортик, скальный низ, затенение по вершинам |
| Небо, облака, облачное море, трава | `src/gfx.js`: градиентный купол, отражения от него, свечение (bloom), ACES |
| Свет | запечён трассировкой лучей в Blender (Cycles): `blender/bakelight.py` — см. ниже |

Рендер сам снижает качество на слабых устройствах: сначала разрешение, затем свечение, затем размер карты теней.

## Запечённый свет

Свет каждого уровня посчитан заранее трассировкой лучей и лежит в `../kubo/light/`:

| Файл | Что в нём |
|---|---|
| `lN_mask.webp` (2048 px) | маска солнечных теней от неподвижной геометрии: островов, постаментов, фонарей, травы. Полутень мягкая и расширяется с расстоянием, как у настоящего солнца |
| `lN_gi.webp` (1024 px) | свет неба с учётом того, что его заслоняет, плюс свет солнца, отражённый от соседних поверхностей |
| `lN_vol.png` | объёмная карта с шагом 0,4 м: видимость солнца и открытость небу в каждой точке уровня |

Как это работает в игре:

- У островов есть вторая развёртка (`uv1`): три листа на остров — верх, кромка, скала. Листы всех островов уровня
  укладываются в один квадрат; плотность на верхних гранях — 96 точек на метр.
- Солнце остаётся «живым»: рельеф по картам нормалей и блики считаются в кадре, маска только гасит солнце в тени.
- Герой, монеты, лифты, блоки и трава освещаются по объёмной карте, поэтому темнеют, заходя в запечённую тень.
- В карту теней реального времени попадают только подвижные объекты — тени не складываются дважды,
  а сама карта теней стала дешевле.
- Если файлы света не загрузились, игра работает с прежним освещением.

Геометрию для запекания выгружает сама игра (`tools/export-level.cjs`), поэтому в Blender попадает ровно то, что видит игрок.
После любого изменения уровней, островов, фонарей или травы свет нужно запечь заново: `blender/light.sh`.

## Структура

```
kubo/                 готовая игра: index.html, game.js, models/*.glb, tex/*.webp, light/*, sounds/*.mp3
kubo-src/
  src/game.js         уровни, физика, управление, меню, сохранения (ключи localStorage kubo_*)
  src/gfx.js          three.js: загрузка, материалы, острова, небо, герой, фонарь, эффекты, запечённый свет
  src/light.json      размеры объёмных карт и масштаб яркости (пишет bakelight.py)
  src/index.html      разметка и стили
  build.mjs           сборка в ../kubo и в dist/kubo.html (вся игра одним файлом)
  blender/            построение моделей и текстур (Blender как модуль Python)
  tools/export-level.cjs  выгрузка неподвижной геометрии уровней для запекания света
  tools/test.cjs      проверка механик на всех уровнях
  tools/shot.cjs      снимки уровня с заданных ракурсов
```

## Сборка игры

Нужен Node.js 22 или новее.

```bash
cd kubo-src
npm ci
npm run build     # пишет ../kubo/game.js, ../kubo/index.html и dist/kubo.html
```

Модели, текстуры, звуки и запечённый свет сборка берёт из `../kubo/` — пересобирать их в Blender для правок кода не нужно.

## Пересборка графики

Нужны Python 3.13 и пакеты `bpy` (Blender как модуль), `numpy`, `pillow`:

```bash
pip install bpy numpy pillow
cd kubo-src/blender
./all.sh          # текстуры, набор предметов, фонарь, свет → ../../kubo/models, ../../kubo/tex, ../../kubo/light
./light.sh        # только свет уровней
```

Запекание идёт на процессоре (Cycles). На двух ядрах набор предметов запекается около 4,5 минуты, фонарь — около 1,5,
свет трёх уровней — около 25 минут. Для `light.sh` нужны ещё собранная игра и Playwright с Chromium (как для проверки ниже).
Игра собрана с Blender 5.3.0; `all.sh` повторяет команды, которыми получены файлы в `../kubo/`.

## Проверка

```bash
npm run build
npx playwright install chromium      # один раз
npm i --no-save playwright
node tools/test.cjs
```

Тест запускает игру в Chromium и на каждом уровне проверяет: каждая платформа держит героя, все монеты собираются,
блоки реагируют на удар головой снизу, каждый падающий настил держит, падает и возвращается, каждый лифт в 12 фазах
движения принимает героя и везёт его полный период, падение возвращает к последнему чекпоинту, финиш засчитывается.
