# Кубо — приложение Android

Оболочка [Capacitor](https://capacitorjs.com) вокруг игры из папки [`../kubo/`](../kubo/): игра ставится на телефон как обычное приложение и работает без интернета.

## Готовый APK

Собирается автоматически на GitHub при каждом изменении игры или этой папки
(`.github/workflows/kubo-apk.yml`) и выкладывается по постоянной ссылке:

**https://github.com/EmptyFoxs/Game/releases/download/apk/Kubo.apk**

Установка: открыть ссылку на телефоне, скачать файл, открыть его и разрешить установку из этого источника.
Новая версия ставится поверх старой, сохранения остаются.

## Что добавляет оболочка

- полноэкранный режим: строка состояния и панель навигации скрыты, появляются на время по свайпу от края;
- экран не гаснет во время игры;
- кнопка «назад»: в игре — пауза, на паузе — продолжить, на экранах финиша и авторов — в меню, в меню — свернуть приложение;
- значок и заставка с героем.

Код оболочки: `android/app/src/main/java/io/github/emptyfoxs/kubo/MainActivity.java`.

## Сборка на своём компьютере

Нужны Node.js 22+, JDK 21 и Android SDK (ставится вместе с Android Studio).

```bash
cd kubo-app
npm ci
npm run apk        # копирует ../kubo в проект и собирает android/app/build/outputs/apk/release/app-release.apk
```

Значки пересобираются из `assets/` командой `npm run icons`.

## Подпись

APK подписывается ключом `android/keystore/kubo-sideload.p12`. Он лежит в репозитории открыто и нужен только затем,
чтобы у всех сборок была одна подпись и обновления ставились поверх. Для публикации в магазине (Google Play, RuStore)
нужен отдельный закрытый ключ, который в репозиторий не кладут.
